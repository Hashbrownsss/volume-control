# **Hand Tracking System Volume Controller**

This project demonstrates how to control the system's volume using **hand tracking** with **OpenCV** and the **MediaPipe** library. By detecting and tracking the distance between specific fingers (e.g., thumb and index), the system dynamically adjusts the volume. It's an interactive and fun way to control your computer's audio without touching the keyboard or mouse.

---

## **Features**
- Tracks hand movements in real-time using a webcam.
- Measures the distance between the thumb and index finger to set the system volume.
- Displays a visual cue (line and circle) for finger tracking and distance calculation.
- Real-time volume adjustment with smooth transitions.

---

## **Technologies Used**
- **Python**: Core programming language.
- **OpenCV**: For capturing and processing video frames.
- **MediaPipe**: For hand detection and tracking.
- **PyCaw**: For controlling the system volume.
